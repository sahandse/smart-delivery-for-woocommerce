# ارسال هوشمند ووکامرس

افزونه انتخاب و مدیریت هوشمند تاریخ ارسال سفارش برای WooCommerce.

## ویژگی‌ها
- فارسی / انگلیسی / خودکار
- تقویم شمسی ایران یا میلادی
- تعیین ۰ تا ۷ روز آماده‌سازی سفارش
- تعطیلی هفتگی و تعطیلات خاص
- ساعت برش (Cut-off)
- تنظیمات جداگانه برای پیک موتوری
- ۴ مدل رابط کاربری: کارت گرافیکی، چیپ، کشویی و لیست مینیمال
- اعتبارسنجی تاریخ در Checkout
- ذخیره تاریخ ارسال در سفارش
- سازگار با WooCommerce HPOS

## نصب
پوشه افزونه باید با نام `smart-delivery-for-woocommerce` داخل `wp-content/plugins/` قرار گیرد.
