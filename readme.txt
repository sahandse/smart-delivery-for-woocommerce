Smart WooCommerce delivery scheduling with Persian/English UI, Jalali/Gregorian calendars, Iran holidays and a compact mini-calendar.

== Features ==
* Persian, English, or automatic interface language
* Persian Jalali or Gregorian calendar
* Built-in Iran official holidays for 1404-1406
* Iranian occasion labels
* Configurable blocked days after order
* First working day after holidays becomes available
* Daily cutoff time and motorcycle courier exception
* Mini calendar plus cards, pills, dropdown and list layouts
* Cart-to-checkout date persistence via WooCommerce session
* HPOS compatibility declaration
