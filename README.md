# Smart Delivery for WooCommerce

افزونه فارسی/انگلیسی انتخاب تاریخ تحویل برای WooCommerce با تقویم شمسی و میلادی، تعطیلات ایران و Mini Calendar مینیمال.

## ویژگی‌های نسخه 1.4.0
- رابط فارسی، انگلیسی یا خودکار
- تقویم شمسی ایران یا میلادی
- تعطیلات رسمی ایران برای ۱۴۰۴ تا ۱۴۰۶
- نمایش مناسبت‌های ایرانی
- فاصله ارسال ۱ یا ۲ روز و عبور خودکار از تعطیلات
- نمایش در سبد خرید و تسویه‌حساب
- Mini Calendar کوچک و ریسپانسیو
- انتخاب اندازه Compact یا Comfortable
- راهنمای رنگ‌ها، تاریخ انتخاب‌شده و مشخص‌کردن اولین روز قابل ارسال
- ذخیره تاریخ با Ajax و حفظ انتخاب تا Checkout
- چند UI جایگزین: کارت، کپسولی، لیست و Dropdown
- سازگاری با WooCommerce HPOS

## نصب
فایل ZIP را از پنل وردپرس در مسیر افزونه‌ها → افزودن افزونه → بارگذاری افزونه نصب کنید.

پوشه افزونه باید همیشه:
`smart-delivery-for-woocommerce`
