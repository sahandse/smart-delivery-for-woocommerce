== Description ==
Smart Delivery for WooCommerce adds a delivery-date selector to WooCommerce checkout and lets administrators configure preparation days, weekly days off, special holidays, cut-off time, Persian/Gregorian calendar, language and display style.

== Installation ==
1. Upload the smart-delivery-for-woocommerce folder to /wp-content/plugins/.
2. Activate the plugin.
3. Open WooCommerce > ارسال هوشمند.
